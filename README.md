# 一页诗

一个简单、安静的古诗网页。收录八首经典五言绝句，提供主题筛选、诗文搜索和随机阅读，适配手机与电脑。

## 内容与隐私

- 发布文件仅包含 HTML、CSS、JavaScript、自制 SVG 图标及本说明。
- 诗文为古代作品，阅读短评为本项目原创。
- 不含个人资料、账号凭据、密钥、聊天记录或本地文件。
- 不加载外部字体、图片、脚本、统计或广告；搜索词只在当前页面内处理。
- 托管平台会按其自身政策处理常规访问请求。

## 本地阅读

直接用浏览器打开 `index.html`，无需安装依赖或构建。

## GitHub Pages

将本目录中的文件提交到仓库的 `main` 分支，然后在仓库 **Settings → Pages** 中选择 **Deploy from a branch**、`main`、`/ (root)` 并保存。

全部资源使用相对路径，支持 GitHub Pages 项目站点。
